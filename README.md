# NEWSPI (뉴스피)

> 뉴스를 뽑고, 읽고, 투자하라. 읽으면 벌고, 알면 오른다.

NEWSPI는 뉴스를 읽고 객관식 퀴즈로 가상 코인을 얻은 뒤, 관련 **가상 이슈 지수**를 매매하는 게임형 뉴스 MVP입니다. 로그인과 데이터베이스 없이 브라우저의 `localStorage`에 진행 상황을 저장합니다.

## 시작하기

Node.js 20.9 이상과 npm이 필요합니다.

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. API 키 없이도 12개의 명확히 표시된 데모 시나리오로 모든 게임 흐름을 체험할 수 있습니다.

배포용 확인:

```bash
npm run lint
npm run build
npm run start
```

## 환경변수

`.env.local`에 다음 값을 선택적으로 설정합니다. 이 파일은 Git에서 제외됩니다. 키에 `NEXT_PUBLIC_` 접두사를 붙이지 마세요.

| 변수 | 용도 |
| --- | --- |
| `NAVER_CLIENT_ID` | NAVER Cloud NAVER API HUB Client ID |
| `NAVER_CLIENT_SECRET` | NAVER Cloud NAVER API HUB Client Secret |
| `OPENAI_API_KEY` | OpenAI API 키 |
| `OPENAI_MODEL` | 분석 모델. 미설정 시 `gpt-4o-mini` |

NAVER Cloud 콘솔의 NAVER API HUB에서 뉴스 검색 권한이 있는 애플리케이션을 등록하고 발급받은 키를 사용합니다. NEWSPI는 [NAVER API HUB 뉴스 검색 API](https://api.ncloud-docs.com/docs/naver-api-hub-search-news)의 JSON 엔드포인트를 서버에서 호출하며 `display=30`, `start=1`, `sort=date`, `format=json`을 사용합니다. AI 분석은 서버의 OpenAI Responses API에서 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)로 응답 형식을 제한합니다.

## 기능과 데모 순서

1. 홈에서 초기 잔액 **100 C**를 확인합니다.
2. **룰렛 돌리기**를 누르면 **10 C**가 차감되고 7개 뉴스 분야 중 하나의 카드를 뽑습니다. 뉴스 요청 자체가 실패하면 10 C를 돌려줍니다.
3. `LIVE` 또는 `DEMO` 배지, 출처, 3줄 요약, 왜 중요한가, 원문 또는 주제 참고 링크를 확인합니다.
4. 실시간 뉴스는 원문 본문을 읽어 퀴즈를 만듭니다. **퀴즈 시작** 후 정답을 고릅니다. 첫 정답 100 C, 첫 오답 뒤 두 번째 정답 50 C입니다. 같은 기사에 대한 보상은 한 번만 지급됩니다.
5. **관련 이슈 거래소 보기**에서 정수 수량을 입력해 매수합니다. 잔액과 보유 수량을 초과한 거래는 거절됩니다.
6. 상단과 거래소의 카운트다운을 확인합니다. **1분마다 7개 가상 이슈 가격이 자동 변동**하고 보유 자산 평가액도 바뀝니다. 룰렛 기사 분석에서 호재나 악재가 확인되면 관련 이슈 하나가 즉시 약 3% 움직입니다. 중립 기사는 가격을 바꾸지 않습니다.
7. **내 포트폴리오**에서 총자산, 평균 매수가, 현재가, 보유 이슈의 평가손익과 투자 수익률을 확인합니다.
8. 새로고침해도 상태가 유지됩니다. 상단의 **데이터 초기화**로 다시 시작할 수 있습니다.
9. 코인이 10 C 미만이면 **행복한 뒤주** 탭에서 응원 문장을 정확히 따라 적고 제출해 **문장당 1 C**를 받을 수 있습니다. 문장 목록은 반복되므로 0 C에서도 다시 시작할 수 있습니다.

## 실패와 예외 처리

- 네이버 키가 없거나 인증·한도·네트워크·응답 형식에 문제가 있거나 최근 기사 후보가 없으면, 요청한 분야의 **DEMO 카드**로 자동 전환합니다. 데모 카드는 실제 기사로 오해하지 않도록 제목과 배지에 표시되며, 링크는 원문이 아닌 주제 참고 사이트입니다.
- 실시간 뉴스는 서버에서 원문 링크를 읽고 Mozilla Readability로 본문을 추출합니다. 원문을 읽을 수 없으면 네이버 뉴스 링크를 한 번 더 시도합니다. 유효한 본문을 확보하지 못하거나 OpenAI 키·호출·형식 검증에 문제가 있으면 **제목과 네이버 description을 그대로** 보여주고 퀴즈를 비활성화합니다. 데모 카드는 미리 작성한 요약과 퀴즈를 사용합니다.
- AI가 입력 정보만으로 사실 확인 가능한 퀴즈를 만들 수 없다고 판단하면 `insufficient` 상태를 표시하고 해당 퀴즈를 비활성화합니다.
- 호재·악재 판단은 AI가 제시한 근거 문구가 기사 본문에 실제로 있는 경우에만 적용합니다. 근거가 없거나 AI 분석에 실패하면 중립으로 처리하고 기사로 인한 가격 변동은 없습니다. 데모 카드에는 미리 작성한 판정을 사용합니다. 같은 기사는 다시 뽑아도 가격에 중복 반영되지 않습니다.
- 추출한 본문 전체를 서버에서만 AI 입력으로 사용하며, 화면이나 localStorage에 본문을 저장하지 않습니다. 정답과 근거 문구가 추출 본문에 있는지도 검사합니다. 이전 버전의 제목·설명 기반 AI 퀴즈 캐시는 새 퀴즈에 재사용하지 않습니다.
- 비정상적인 `localStorage` 값은 안전한 초기 상태로 정규화합니다. 퀴즈 시도 횟수와 보상 기록도 저장합니다.
- 이전 버전의 진행 기록은 유지합니다. 진행하지 않은 기존 기본 잔액 1,000 C는 100 C로 전환하며, 기존 진행 기록을 완전히 새로 시작하려면 상단의 **데이터 초기화**를 사용합니다.

## MVP 범위와 제한

- 거래 대상은 실제 기업 주식이 아닌 **7개 가상 이슈 지수**입니다. 1분 변동은 브라우저에서 이슈별 무작위 방향·약 0.5~1.5% 폭으로 계산하며, 기사 반영 폭은 앱에 고정된 약 3%입니다. 최소 가격은 10 C입니다. 실제 시장 시세가 아니며 브라우저 간 가격은 동기화되지 않습니다.
- 다음 변동 시각과 가격은 `localStorage`에 저장됩니다. 새로고침 후에도 타이머가 이어지며, 탭을 오래 닫았다 다시 열면 최대 60분치 변동을 반영한 뒤 다음 1분부터 재개합니다.
- 전체 투자 수익률은 **현재 보유 이슈의 미실현 평가손익 ÷ 보유 원가**입니다. 매도 완료분의 실현손익 통계와 멀티 기기 동기화는 제공하지 않습니다.
- 실시간 뉴스 검색은 네이버 결과를 무작위로 선택하므로 키가 있어도 분야별 최신 기사 후보가 없는 경우 데모로 전환될 수 있습니다.
- 일부 언론사는 자동 접근을 차단하거나 본문을 JavaScript로만 표시합니다. 이런 기사는 원문 링크는 열 수 있어도 원문 기반 퀴즈를 제공하지 못합니다.
- 인증, 회원가입, 데이터베이스, 멀티플레이, 실제 투자, 관리자 기능은 범위에 포함되지 않습니다.

모든 코인과 가격은 게임용 가상 데이터이며 실제 금융상품이나 투자 조언이 아닙니다.
